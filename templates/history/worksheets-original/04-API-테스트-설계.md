입력: `docs/requirements.md` 4·5절(취소 규칙, API 계약)과 8절, `docs/openapi.json`, `src/test/java/com/example/enrollment/support/ApiTestSupport.java`·`TestData.java`.
순서: ① A절 설계표를 직접 채운다 → ② AI에게 아래 첫 요청을 보내 테스트 코드 초안을 받는다 → ③ `practice/ApiPracticeTest.java`에 넣어 실행하고, 응답·데이터·부작용 확인이 각각 들어 있는지 관찰한다 → ④ 빠지거나 틀린 것만 고친다(충분하면 그대로 두고 이유를 적는다) → ⑤ B절에 인수 시나리오를 적는다 → ⑥ 강사가 보여 주는 기준 예제와 비교하고 D절을 적는다.

# AI로 테스트 만들고 확인하기

학생 저장소: https://github.com/frentis-edu-code/course-enrollment-testing-student (받기·준비: README)

이번 수업의 복사용 정본입니다. 현재 장표와 같은 새 요청(v4 제안)이며 과거 AI 실행 원문이 아닙니다. 실제 생성·시험 성공은 별도 확인해야 합니다.

AI 요청 → 근거·범위 검토 → 실제 실행 기록 확인. Java는 프로젝트 루트, 화면 E2E는 frontend에서 실행합니다. Windows에서는 ./mvnw 대신 .\mvnw.cmd를 씁니다.

새 Java 테스트는 practice 아래 *Test.java와 해당 태그를 지키고 신규 이름·실행 수·건너뜀을 확인합니다. 옛 양식은 참고이며 선행 작성 관문이 아닙니다. TDD 종료·E2E 대기·단원5 기준선과 제한 수정·복구는 실습-진행-안내.md를 함께 읽습니다.

# 요구 메모(다듬기 전)

교육 담당자가 남긴 짧은 요구입니다. 질문과 합의로 규칙을 구체화하기 전의 메모입니다. 이 메모에서 "결과가 갈릴 수 있는 지점"과 "질문해야 할 곳"을 찾습니다.
팀이 이 메모의 모호한 부분을 질문하고 합의해 다듬은 결과는 `docs/requirements.md`에 있습니다. 요구 메모와 합의 결과의 차이를 살펴볼 때 참고합니다.

## 메모

- 사원이 사내 교육 과정을 온라인으로 신청하고 취소할 수 있어야 한다.
- 과정마다 정원이 있고, 정원이 차면 더 받지 않는다.
- 같은 과정은 한 번만 신청할 수 있다.
- 신청은 마감 전까지, 취소는 교육 시작 하루 전까지 할 수 있다.
- 한 사람이 너무 많은 과정을 한꺼번에 신청하지 못하게 한다.

## 화면(교육용 가정)

- 과정 목록: 과정명, 정원, 잔여석, `신청` 버튼. 잔여석이 0이면 `정원 마감` 표시와 버튼 비활성.
- 결과 메시지: 신청·취소 결과를 화면 위쪽 알림 영역에 보여 준다.
- 내 신청 목록: 과정명, 상태(신청됨/취소됨), `취소` 버튼. 누르면 "정말 취소하시겠습니까?" 확인 창이 뜨고, 확인해야 취소를 요청한다.
- 화면 위쪽에 실습 기준 시각과 "교육용, 인증·권한 없음" 안내를 표시한다.

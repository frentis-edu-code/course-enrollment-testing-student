# 실습 5. 변경 뒤 회귀 확인과 결과 정리 — 선택 기록 양식

> 필수 양식이 아닙니다. AI에 요청하기 전에 채우지 않으며, 기록이 필요할 때만 씁니다. 요청문은 [AI 요청문](../AI-요청문.md)의 “실습 5: AI 영향 분석 요청과 재실행 대상 검토”와 “실습 5: 실행 기록으로 근거표와 보고 만들기”를 복사해 씁니다. 기준선·패치·복구 순서는 [실습 진행 안내](../실습-진행-안내.md)의 “단원 5: 분석·기준선·패치·재검증”을 따릅니다. 이전 수업의 원래 양식은 `templates/history/worksheets-original/`에 그대로 보존되어 있습니다.

## 수업 흐름

1. AI가 프로젝트 루트의 `lab5-change.patch`, 요구 문서의 신청·취소 규칙, 지금 있는 테스트를 읽고 영향 분석만 합니다.
2. 단원 4의 API 테스트(예: `EnrollmentApiTest.java`)에 “취소한 과정을 같은 사원이 다시 신청” 테스트를 보강하고, 패치 적용 전에 실행해 기준선을 남깁니다.
3. 허용된 작업 사본에서 패치 적용 → 같은 테스트 → 필요하면 조회 파일만 제한해 수정 → 같은 테스트·선택 묶음·전체 재실행 → 복구합니다.
4. 실제 실행 기록으로 AI에게 근거표만 받고, 원문과 대조해 고친 표로 보고를 요청합니다.

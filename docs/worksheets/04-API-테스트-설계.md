# 실습 4. API·화면 테스트 검토 — 선택 기록 양식

> 필수 양식이 아닙니다. AI에 요청하기 전에 채우지 않으며, 기록이 필요할 때만 씁니다. 요청문은 [AI 요청문](../AI-요청문.md)의 “실습 4: AI 요청과 API 테스트 검토·실행”과 “실습 4: React 신청·취소 화면의 E2E 테스트”를 복사해 씁니다. 순서와 화면 E2E 주의는 [실습 진행 안내](../실습-진행-안내.md)를 따릅니다. 이전 수업의 원래 양식은 `templates/history/worksheets-original/`에 그대로 보존되어 있습니다.

## 수업 흐름

1. API: AI가 `docs/requirements.md`의 취소 규칙과 `src/test/java/com/example/enrollment/support/ApiTestSupport.java`를 보고, 정원이 찬 C-101에서 한 명이 취소한 뒤 다른 사원이 신청하는 테스트를 만듭니다. 만들 파일 예시는 practice의 `EnrollmentApiTest.java`이며 아직 없는 파일입니다. 직접 실행: 프로젝트 루트에서 `./mvnw test -Dgroups=api`.
2. 따라 하기: 같은 파일에 “같은 사원이 이미 신청한 과정에 다시 신청” 테스트를 더해 달라고 요청합니다.
3. 화면: AI가 요구 문서의 화면 설명과 `frontend/e2e/helpers.js`를 보고 신청·취소 화면 테스트를 만듭니다. 만들 파일 예시는 `frontend/e2e/enrollment-flow.spec.js`이며 아직 없는 파일입니다. 직접 실행: `frontend`에서 `npm run e2e`(jar와 Chromium 준비 필요).
